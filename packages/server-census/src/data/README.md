# Vendored table index

`table-index.json.gz` backs `census_search_tables` (ADR-014 §7, #175): a compact, gzipped
lookup from topic to Census table/group id, so a model can find `B19013` for "median household
income" without a runtime call. It is generated once by `../scripts/build-table-index.mts` from
two **public, keyless** Census Data API metadata endpoints and vendored here — no network at
query time, no runtime database.

## What it covers

Datasets whose path (`c_dataset` joined by `/`) is one of `acs/acs1`, `acs/acs1/subject`,
`acs/acs1/profile`, `acs/acs5`, `acs/acs5/subject`, `acs/acs5/profile`, `dec/pl`, `dec/dhc`, for
vintages 2019 onward — the ACS and decennial endpoints M8 serves (ADR-014 §7, §10). Other
datasets in `data.json` (SAIPE, PEP, economic censuses, …) are out of scope until a later
milestone adds them.

## Regenerating

`npx tsx packages/server-census/scripts/build-table-index.mts` (network; run deliberately, never
in CI or tests — CLAUDE.md: agency APIs are never called in unit tests, and this call is to
public dataset/group metadata, not agency data, which is why it's a build-time script under
`scripts/` rather than a server tool under `src/`):

1. Fetches `https://api.census.gov/data.json` (the API's full dataset catalog; no key) and
   selects the (dataset, vintage) pairs in scope above.
2. For each, fetches that dataset/vintage's `groups.json`
   (`https://api.census.gov/data/<vintage>/<dataset>/groups.json`; no key) — `{ groups: [{ name,
   description }] }`, where `name` is the table id (`B19013`, `S1701`, `DP04`, `P1`, …).
3. Merges rows, deduplicated per `(id, endpoint)`, accumulating every vintage the table appears
   in as `years`.
4. Writes the array sorted by `endpoint` then `id`, gzips it to `table-index.json.gz`, and prints
   the row count, retrieval date and SHA-256 to record in the table above.

## Schema

Each row: `{ id: string, label: string, endpoint: string, years: number[] }`.

- `id` — the table/group id (e.g. `B19013`, `S1701`, `DP04`, `P1`), the input `census_get_raw`
  takes as `get.group`.
- `label` — the group's Census description (its ALL-CAPS title, e.g. "MEDIAN HOUSEHOLD INCOME IN
  THE PAST 12 MONTHS (IN 2019 INFLATION-ADJUSTED DOLLARS)").
- `endpoint` — the dataset path without a vintage (e.g. `acs/acs5/subject`), the input
  `census_get_raw` takes as `dataset`.
- `years` — the vintages this table appears in for this endpoint, ascending; a table can be
  discontinued or introduced between vintages (e.g. some decennial groups only exist at 2020).

## Loading

`../table-index.ts`'s `loadTableIndex()` gunzips and parses this file once (memoized);
`searchTables()` ranks rows against a free-text query. Neither touches the network — see that
module's tests for the ranking rules.
